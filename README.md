# Winston and Saffron — the show's own feed

This repository holds exactly one thing that matters: **feed.xml**, the RSS feed
for the *Winston and Saffron* podcast.

- Episode audio is hosted on the **Internet Archive** (one item per episode);
  the feed's enclosures point at the Archive's permanent download links.
- Subscribe with the feed URL:
  `https://cdn.jsdelivr.net/gh/jerkbones/winston-and-saffron@main/feed.xml`
- Show cover art lives with the first episode's Archive item (`cover.jpg`).

Executive producer: Luke. Hosts: Winston and Saffron.
